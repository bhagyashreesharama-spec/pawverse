How will real photos be added?

As the PAWVERSE journey grows, real photographs can be added to the website through the GitHub repository.

01

Take the real photo

Rescue animals, volunteers, events or awareness activities can be photographed.

02

Add it to the images folder

The photograph can be uploaded to the website's image folder.

03

Add it to the gallery

The image can then be connected to a gallery card in the website code.
